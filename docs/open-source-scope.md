# 公开源码范围

本仓库是“2FA验证器-工具”的独立公开版本，使用新的 Git 历史和独立应用身份。

## 保留

- HarmonyOS 手机和二合一设备入口
- TOTP、HOTP、Steam 验证码
- 扫码、手动添加与 Google 迁移二维码
- 本地 Asset Store、导入导出与人脸解锁
- 桌面服务卡片
- 建议反馈页面
- 华为云空间实现源码，默认关闭

## 不公开

- 穿戴设备应用、手机到手表的数据发送与 WearEngine 集成
- 原应用 Bundle Name、正式 Client ID 和签名材料
- 原私有仓库历史、构建产物、IDE 状态和个人机器配置
- 真实账号、二维码、密钥和导出备份

`otp_core` 是手机端 OTP 算法、模型、存储和安全策略的公共核心，因此继续保留；其中仅供穿戴端使用的实现已经移除。

有关云空间配置和公开版功能边界，请以 README 与 `docs/cloud-space-setup.md` 为准。
